Mesh Optimization

Use mesh optimization settings to save space.

Go to Model on the avatar's fbx file and set the mesh compression to low, medium, or high, and set the mesh optimization to everything.

The mesh compression can change the appearance of your avatar meshes, so make sure to inspect your avatar after changing these settings to see which mesh compression mode is right for that avatar.

You can configure these settings on any fbx of any other meshes/assets you add to the avatar such as clothing, hair, accessories, etc.
