Materials and Shaders

Quest avatars can only use the VRChat created mobile shaders. These include ToonLit, Matcap Lit, Standard Lite, Toon Standard, Bumped Diffuse, Bumped Map Specular, Diffuse, Lightmapped, Particles>Multiply, and Particles>Additive. Alot of these shaders are legacy and their minimal features have been included in new shaders. The only shaders you need to worry about for Quest is Toon Standard, Standard Lite, and the particle shaders.
